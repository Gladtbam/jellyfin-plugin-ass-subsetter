选择字幕处理方式。子集化模式精简ASS内嵌字体；SUP模式通过libass渲染将ASS转为PGS位图字幕。两种模式互斥。
例如：/fonts/my_anime_fonts;/media/extra_fonts。多个路径请用分号 ; 隔开。(系统默认字体目录已被自动包含，无需填写)
本地字体解析索引 JSON 数据库存储路径。建议保持留空，插件会自动在内部数据目录生成 font_caches.json。
ASS 转 SUP 时的渲染采样帧率。值越高动画越流畅但文件越大（推荐值: 24）。视频分辨率从元数据自动获取。
处理后的临时字幕缓存文件的最大总体积。达到上限后将自动清理最旧的缓存（推荐值: 1024）。
开启后，媒体库添加入库新视频时将自动在后台预处理字幕缓存。
开启后，当检测到用户播放进度接近当前剧集结尾时，自动在后台提前处理下一集的所有 ASS 字幕。
当播放进度达到此百分比时触发下一集的提前处理（推荐值: 85）。
开启后，如果处理失败将无缝返回原始字幕，确保播放不中断。
